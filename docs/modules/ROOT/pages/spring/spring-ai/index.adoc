= Spring AI
:description: Upgrade and migration recipes for Spring AI 1.x and Spring AI 2.x.

Arconia Migrations ships an upgrade recipe for each minor release of Spring AI that it supports.

* *xref:spring/spring-ai/2-1.adoc[Spring AI 2.1].* Migrate to the latest Spring AI 2.1.x release.
